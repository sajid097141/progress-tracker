# PREBOARD — Glass & Lavender Edition

A refreshed visual edition of the Class XII progress tracker.

## What's changed
- Glassmorphism interface in a lavender, lilac, icy-blue and soft-pink palette.
- Light and dark themes with a persistent theme toggle.
- Updated PREBOARD wordmark (no slashes) and cleaner editorial typography.
- Responsive layout for desktop, tablet and mobile.

## Preserved
- Existing chapter syllabus and progress data format.
- Existing localStorage keys for progress, auto-save, stream and PCMB option.
- PCM / PCB / PCMB selection rules, including the PCMB optional subject.
- Search, subject/status filters, collapsible subjects, focus mode and bulk selection.
- Manual save, auto-save, import/export backup and reset confirmation.

## Run the website
Open `index.html` in a browser, or deploy the folder to GitHub Pages. Progress is stored in the current browser's localStorage; use Export to move a backup between devices.

The included Python/Tkinter companion is retained unchanged; the web redesign applies to `index.html`.
