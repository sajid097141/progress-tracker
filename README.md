# PRE//BOARD — Progress Tracker

A minimal black-and-green, browser-based Class XII pre-board syllabus tracker.

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Upload `index.html` to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then click **Save**.
5. Wait for the deployment to finish. The site should be available at:
   `https://sajid097141.github.io/progress-tracker/`

## Features
- Five subject checklists and subject-wise progress
- Overall progress percentage and countdown to 16 November 2026
- Filters for subject and ALL / TODO / DONE
- Auto-save toggle and Save Now button
- Export/import JSON backup and reset confirmation

## Storage note
Progress is stored in the browser's local storage on the current device and browser. It is not automatically synchronized between devices or browsers. Use **Export Backup** and **Import Backup** to transfer it.
