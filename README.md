# PRE//BOARD — Progress Tracker

A minimal black-and-green Class XII pre-board tracker.

## Stream combinations
- **PCM:** English, Physics, Chemistry, Mathematics, Computer Science
- **PCB:** English, Physics, Chemistry, Biology, Computer Science
- **PCMB:** English, Physics, Chemistry, Mathematics, Biology, Computer Science

Use the stream selector in the website to show the relevant subject combination. Mathematics and Biology are separate subjects and can both be enabled with PCMB.

## Publish with GitHub Pages
1. Upload `index.html` to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
4. Your expected URL is `https://sajid097141.github.io/progress-tracker/`.

## Features
- Stream selector for PCM, PCB and PCMB
- Separate Mathematics and Biology checklists
- Subject-wise and overall progress
- Auto-save toggle, manual save, JSON backup export/import
- Progress is stored in the current browser's local storage; use backup export/import to transfer devices.
